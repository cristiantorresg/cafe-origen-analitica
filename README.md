# Analítica de Ventas — Tienda de Café (v0.1)

## ¿Qué es el proyecto?
Es una herramienta de consola en Node.js que toma los registros de ventas de la tienda de café (`datos.js`), calcula indicadores clave en `analitica.js` y muestra un informe ordenado y formateado en pesos colombianos (`reporte.js`).

## ¿Cómo ejecutarlo?
1. Abre la terminal en la carpeta principal del proyecto (asegúrate de tener **Node.js** instalado).
2. Ejecuta el comando del reporte:
   ```bash
   node reporte.js
